BROWSER AUTHENTICATION

USE COOKIES FROM BROWSER?

Some tracks (age-restricted, members-only, or "sign in to confirm") only download when YouTube can see that you are signed in. PLADAZ can use the sign-in from your browser, so you do not have to copy cookies by hand.

IF YOU CONTINUE:
  • yt-dlp, the download tool inside PLADAZ, opens this browser's cookie store on this PC and reads its cookies. The store holds cookies for all websites, not only YouTube.
  • This happens now to check access, and again on every download while Browser Authentication is on.
  • Cookies stay in memory and are used only for yt-dlp's own requests to YouTube. PLADAZ saves only the browser name, never cookie values, and never writes them to the log.
  • PLADAZ never asks for your password and does not bypass browser or Windows protection if access is blocked.

Only continue if you allow this. You can turn it off any time in Settings › Browser Authentication.
