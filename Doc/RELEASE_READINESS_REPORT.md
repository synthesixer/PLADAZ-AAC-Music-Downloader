## 3. เงื่อนไขขวางการ Release (Release Blockers)

1. **ข้อความ Personal Use Disclaimer ฉบับจริง (`TC-029` / `TBA-023`):** ใน [`ui/index.html`](file:///e:/Doc/Code/randombullshit/PLADAZV2/ui/index.html) ยังแสดงข้อความชั่วคราว `[DISCLAIMER TEXT — wording to be supplied by the project owner]` ต้องได้รับข้อความจริงจากเจ้าของโครงการเพื่อนำไปแทนที่และบิลด์ใหม่
2. **ผลการทดสอบบนเครื่อง SNOWSKY ECHO DAP จริง (`TC-015`) และ Micro SD Card จริง (`TC-008`, `TC-019`, `TC-028`):** ต้องมีผลยืนยันจากผู้ใช้ตาม Checklist D, E และ F
3. **การตรวจสอบเงื่อนไขการใช้งานและสัญญาอนุญาตโดยเจ้าของโครงการ (เกณฑ์ข้อ 15):** เจ้าของโครงการต้องเป็นผู้ตรวจทานเงื่อนไขการใช้งานแหล่งข้อมูล รวมถึงรับทราบข้อกำหนด GPLv2+/GPLv3 ของ `mutagen` และ `FFmpeg` (กรณีแจกจ่ายไบนารีต่อให้บุคคลอื่น)
