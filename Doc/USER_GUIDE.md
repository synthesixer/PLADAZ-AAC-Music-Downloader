# PLADAZ — User Guide (คู่มือการใช้งาน)

> **คู่มือการใช้งานโปรแกรม PLADAZ (Personal Music Downloader for SNOWSKY ECHO DAP)**
>
> **เวอร์ชันโปรแกรม:** v1.0.0  
> **ภาษา UI:** ภาษาอังกฤษ (English)  
> **ระบบปฏิบัติการที่รองรับ:** Windows 10 / Windows 11 (64-bit)

---

## 1. การติดตั้งและการเตรียมพร้อมก่อนเปิดแอป (Installation & Setup)

PLADAZ เป็นโปรแกรมแบบ **Portable (`--onedir`)** ไม่ต้องผ่านตัวติดตั้ง (Installer) เพียงแตกโฟลเดอร์ `PLADAZ` ออกมาก็สามารถใช้งานได้ทันที:

1. **โครงสร้างโฟลเดอร์ของแอปพลิเคชัน (`dist\PLADAZ\`):**
   ```text
   PLADAZ\
   ├── PLADAZ.exe         <- ตัวโปรแกรมหลักสำหรับเปิดใช้งาน
   ├── _internal\         <- ไลบรารีระบบ, Assets หน้าบ้าน และ bin\ (ffmpeg.exe, yt-dlp.exe)
   ├── config.json        <- บันทึกการตั้งค่า (สร้างอัตโนมัติเมื่อเปิดแอป)
   ├── history.json       <- บันทึกประวัติดาวน์โหลด (สร้างอัตโนมัติเมื่อเปิดแอป)
   ├── temp\              <- โฟลเดอร์พักไฟล์ชั่วคราว (ล้างอัตโนมัติเมื่อเปิด/ปิดแอป)
   └── logs\              <- บันทึกการทำงานและข้อผิดพลาด (pladaz.log)
   ```
2. **การตั้งค่า `yt-dlp.exe` ครั้งแรก (First-Run Setup — บอร์ด 09):**
   - เมื่อเปิดแอปครั้งแรก หากไม่พบ `yt-dlp.exe` ใน `_internal\bin\` หรือข้าง `PLADAZ.exe` ระบบจะแสดงหน้าต่าง **"First-Run Setup · External Binary Required (`yt-dlp.exe`)"** (บอร์ด 09)
   - ผู้ใช้สามารถเลือกดำเนินการได้ดังนี้:
     - กดปุ่ม **`⬇ DOWNLOAD YT-DLP`** เพื่อให้ระบบดาวน์โหลด `yt-dlp.exe` เวอร์ชันล่าสุดจาก GitHub Official Releases มาติดตั้งโดยอัตโนมัติ
     - กดปุ่ม **`LOCATE FILE…`** เพื่อเลือกไฟล์ `yt-dlp.exe` ที่มีอยู่แล้วในเครื่อง (ระบบจะคัดลอกมาติดตั้งและตรวจสอบ `--version`)
     - กดปุ่ม **`CHECK AGAIN`** เพื่อตรวจสอบซ้ำหลังจากวางไฟล์ด้วยตนเอง
   - เมื่อตรวจพบสถานะ `READY` แล้ว ให้กดปุ่ม **`OPEN PLADAZ ›`** เพื่อเข้าสู่โปรแกรม

## 2. การเปิดใช้งานครั้งแรกและการยอมรับเงื่อนไข (First Launch & Disclaimer)

1. ดับเบิลคลิกเปิดไฟล์ `dist\PLADAZ\PLADAZ.exe`
2. ระบบจะแสดงหน้าต่าง **Personal Use Disclaimer** (บอร์ด 04):
   - อ่านข้อกำหนดการใช้งานสำหรับเก็บสำรองข้อมูลและฟังเพลงส่วนบุคคลบนเครื่องเล่น SNOWSKY ECHO DAP
   - ติ๊กถูกที่ช่อง **"I have read and accept these terms — for personal use only."**
   - กดปุ่ม **`ACCEPT & CONTINUE`** เพื่อเข้าสู่หน้าจอหลัก (หรือกด **`QUIT APPLICATION`** หากไม่ยอมรับ)
   *(การกดยอมรับจะบันทึกสถานะ `"disclaimer_accepted": true` ลงใน `config.json` และจะไม่แสดงขึ้นมาอีกในการเปิดครั้งต่อไป)*

## 3. การเลือก Micro SD Card หรือโฟลเดอร์ปลายทาง (Destination Setup)

1. เสียบ Micro SD Card หรือการ์ดรีดเดอร์เข้ากับคอมพิวเตอร์
2. เปิดหน้า **SD Card / Storage** (คลิกแท็บ **`Storage`** ด้านซ้าย หรือคลิกที่แถบการ์ดด้านบน — บอร์ด 03):
   - กดปุ่ม **`↻ SCAN REMOVABLE DRIVES`** เพื่อค้นหาไดรฟ์ถอดได้ในเครื่อง
   - กดปุ่ม **`USE THIS CARD`** บนการ์ดที่ตรวจพบ หรือกดปุ่ม **`CHOOSE FOLDER…`** เพื่อเลือกโฟลเดอร์ปลายทางผ่านหน้าต่างของ Windows (เช่น `E:\` หรือ `E:\Music`)
   - นอกจากนี้ยังสามารถเปลี่ยนโฟลเดอร์ปลายทางได้ในหน้า **Settings** (บอร์ด 06) โดยกดปุ่ม **`BROWSE…`**
3. แถบสถานะการ์ดด้านบนและในหน้า Storage จะแสดง:
   - ป้ายสถานะการ์ดตามจริง: **`READY`**, **`UNSET`**, **`DISCONNECTED`**, หรือ **`READ-ONLY`**
   - ปริมาณพื้นที่ว่างและแถบความจุแบบ 10 ช่อง (10-segment bar)

---

## 4. การเพิ่มเพลงเข้าคิว (Enqueueing Tracks)

1. คัดลอกลิงก์จาก **YouTube** (`youtube.com`, `youtu.be`) หรือ **YouTube Music** (`music.youtube.com`)
   - รองรับลิงก์เพลงเดี่ยว (Single Track)
   - รองรับลิงก์เพลย์ลิสต์ (Playlist)
   - รองรับลิงก์อัลบั้ม (Album)
2. วางลิงก์ลงในช่องป้อน URL ด้านบน (วางทีละลิงก์ ไม่ว่าจะเป็นลิงก์เพลงเดี่ยวหรือลิงก์เพลย์ลิสต์/อัลบั้ม)
3. กดปุ่ม **`+ ADD TO QUEUE`** (หรือกดปุ่ม `Enter`)
   - ระบบจะดึงข้อมูลรายการเพลงและเพิ่มทุกเพลงเข้าคิวด้วยสถานะ **`Queued`** (`DEC-048`: เพิ่มทุกเพลงในเพลย์ลิสต์เข้าคิวโดยตรง)

## 5. การควบคุมคิวดาวน์โหลด (Queue Control)

* **ปุ่ม `▶ START QUEUE`:**
  - เริ่มประมวลผลเพลงในคิวตามลำดับทีละเพลง (**Sequential Worker**)
  - สถานะเพลงที่กำลังทำจะเปลี่ยนเป็น **`Downloading`** พร้อมแถบความคืบหน้าแบบ 10 ช่อง (10-segment bar) และแสดงขั้นตอนย่อยตามจริง (`Checking SD Card` → `Fetching Info` → `Resolving Metadata` → `Checking Duplicate` → `Waiting for Conflict Choice` → `Downloading Stream` → `Processing Audio (AAC-LC)` → `Writing M4A Tags & Cover` → `Validating Output` → `Copying to SD Card`)
* **ปุ่ม `■ CANCEL CURRENT` หรือปุ่ม `✕` ในแถวเพลงที่กำลังดาวน์โหลด:**
  - เมื่อกดยกเลิกเพลงที่กำลังดาวน์โหลด ระบบจะแสดงหน้าต่างยืนยัน **Cancel Active Download?** (บอร์ด 11)
  - กด **`KEEP DOWNLOADING`** เพื่อทำต่อ หรือกด **`YES, CANCEL TASK`** เพื่อยกเลิก
  - เมื่องานถูกยกเลิก สถานะของเพลงนั้นจะเปลี่ยนเป็น **`Failed`** ด้วยรหัส `ERR_TASK_CANCELLED` ล้างไฟล์ชั่วคราวใน `temp/` ทิ้ง และหยุดคิวชั่วคราวเพื่อรอคำสั่งจากผู้ใช้ (`DEC-049`)
* **ปุ่ม `▶ RESUME QUEUE`:**
  - แสดงขึ้นเมื่อคิวหยุดชั่วคราว (เช่น หลังกดยกเลิกงานปัจจุบัน หรือหลังการ์ดหลุดแล้วเสียบการ์ดกลับ) กดเพื่อให้คิวประมวลผลเพลงที่รออยู่ในสถานะ `Queued` ต่อไป
* **ปุ่ม `↻` (Retry) / `✕` (Remove) / `CLEAR COMPLETED`:**
  - กดปุ่ม `↻` ที่แถวเพลงสถานะ `Failed` (หรือปุ่ม **`↻ RETRY TASK`** ในหน้าต่างรายละเอียดเพลง) เพื่อนำเพลงกลับเข้าคิวใหม่
  - กดปุ่ม `✕` เพื่อลบเพลงออกจากคิว หรือกด **`CLEAR COMPLETED`** เพื่อล้างรายการที่เสร็จสิ้นแล้วออกจากหน้าคิว

## 6. การจัดการไฟล์ซ้ำในโฟลเดอร์ปลายทาง (Conflict Resolution)

หากบน Micro SD Card มีไฟล์เพลงชื่อเดียวกันอยู่แล้ว ระบบจะหยุดรอที่ขั้นตอน `Waiting for Conflict Choice` และแสดงหน้าต่าง **File Already Exists on SD Card** (บอร์ด 05) ก่อนเริ่มดาวน์โหลดเสียง:

* **`OVERWRITE`:** เขียนทับไฟล์เดิม (ระบบจะคัดลอกผ่านไฟล์ชั่วคราว `.pladaz-tmp` และตรวจสอบขนาดไฟล์ก่อน `os.replace` เพื่อป้องกันไฟล์เดิมเสียหายหากการ์ดหลุดกลางคันตาม `DEC-040`)
* **`SKIP`:** ข้ามเพลงนี้ (เอางานออกจากคิวทันทีโดยไม่ดาวน์โหลดเสียงตาม `DEC-039`)
* **`KEEP BOTH`:** เก็บทั้งสองไฟล์ (สร้างชื่อไฟล์ใหม่โดยเติม ` (1)`, ` (2)` ต่อท้าย เช่น `01 - Track (1).m4a` ตาม `DEC-019`)
* **ตัวเลือกขอบเขตการใช้คำตอบซ้ำ (Apply Scope):**
  - **Apply to all conflicts in this album (`<Album Artist>/<Album>`):** นำคำตอบนี้ไปใช้กับเพลงซ้ำทุกเพลงที่อยู่ในโฟลเดอร์อัลบั้มเดียวกัน
  - **Apply to all conflicts in current queue:** นำคำตอบนี้ไปใช้กับเพลงซ้ำทุกเพลงในรอบคิวปัจจุบัน (และรีเซ็ตเมื่อคิวว่างตาม `DEC-044`)
* กดปุ่ม **`CONFIRM CHOICE`** เพื่อดำเนินการต่อ (หากเผลอปิดหน้าต่างไป สามารถกดปุ่ม **`OPEN PROMPT`** ที่แถวเพลงในคิวเพื่อเปิดหน้าต่างเลือกใหม่ได้)

## 7. หน้าการตั้งค่า (Settings — บอร์ด 06)

* **Default Destination Folder:**
  - กดปุ่ม **`BROWSE…`** เพื่อเปลี่ยนโฟลเดอร์ปลายทางเริ่มต้น
* **Album Art Enforcement (`Require album art to pass Output Validator` — `DEC-031`, `DEC-050`):**
  - **ปิด (ค่าเริ่มต้น `False`):** หากหาภาพปกไม่ได้ เพลงยังคงบันทึกสำเร็จ (`Completed`) พร้อมป้ายเตือน `! No cover`
  - **เปิด (`True`):** หากหาภาพปกไม่ได้ ระบบจะไม่คัดลอกไฟล์ลงการ์ด และปรับสถานะงานเป็น `Failed` (`ERR_VALIDATOR_MISSING_COVER`)
* **Browser Authentication & Cookies (`Option C: Automatic Detection with Explicit User Consent` — `DEC-052`):**
  - **การตรวจจับและแนะนำเบราว์เซอร์อัตโนมัติ:** เมื่อเปิดหน้า Settings ระบบจะสแกนหาเบราว์เซอร์ที่ติดตั้งในเครื่อง Windows และตรวจพบโปรไฟล์คุกกี้ (เช็กเฉพาะการมีอยู่ของไฟล์ ไม่เปิดอ่านข้อมูล) พร้อมแนะนำเบราว์เซอร์ที่เหมาะสมผ่านป้าย **`RECOMMENDED`** โดยจะจัดลำดับแนะนำ **Firefox** เป็นอันดับหนึ่ง เนื่องจากเบราว์เซอร์ตระกูล Chromium บน Windows ยุคใหม่ (เช่น Chrome, Edge) มักเปิดระบบความปลอดภัยระดับ OS (DPAPI / App-Bound Encryption) หรือล็อกไฟล์ฐานข้อมูล SQLite ทำให้แอปภายนอกอ่านคุกกี้ไม่ได้
  - **การขอความยินยอมอย่างชัดแจ้ง (Explicit Consent Dialog):** เมื่อกดปุ่ม **`USE BROWSER`** ระบบจะเปิดหน้าต่างยืนยันสิทธิ์ระบุชื่อเบราว์เซอร์ ชี้แจงวัตถุประสงค์ (ใช้สำหรับเพลงจำกัดอายุ/เนื้อหาสมาชิก) และยืนยันความปลอดภัยว่าจะอ่านเฉพาะคุกกี้เซสชันที่จำเป็นต่อการดาวน์โหลด ไม่แตะต้องรหัสผ่าน ประวัติการท่องเว็บ หรือข้อมูลส่วนบุคคลใดๆ ทั้งสิ้น โดยโฟกัสที่ปุ่มปลอดภัย **`CANCEL`** ก่อน
  - **การทดสอบและแสดงผลด้วยภาษาง่าย:** เมื่อกดยืนยัน **`ALLOW & TEST`** ระบบจะส่งคำสั่งไปยัง `yt-dlp` เพื่อทดสอบอ่านจำนวนคุกกี้แบบไม่ผ่านเน็ตเวิร์ก หากสำเร็จสถานะจะเปลี่ยนเป็น **`✓ ACTIVE: <BROWSER>`** สีมิ้นต์ หากไม่สำเร็จจะแสดงสถานะ **`! INACTIVE: <BROWSER>`** พร้อมกล่องข้อความแนะนำขั้นตอนแก้ไขเป็นภาษาง่ายทันที เช่น แนะนำให้ปิดหน้าต่างเบราว์เซอร์ทั้งหมดหากไฟล์ถูกล็อก หรือแนะนำให้เปลี่ยนไปใช้ Firefox
  - **ปุ่ม `TEST` และ `REMOVE`:** กดปุ่ม **`TEST`** เพื่อทดสอบอ่านคุกกี้จากเบราว์เซอร์ที่เลือกได้ตลอดเวลา หรือกด **`REMOVE`** เพื่อยกเลิกการเชื่อมต่อคุกกี้ทันที
  - **ทางเลือกสำรอง (Manual Fallback: `cookies.txt`):** หากระบบรักษาความปลอดภัยของ Windows ป้องกันไม่ให้แอปอ่านคุกกี้เบราว์เซอร์ได้ ผู้ใช้ยังสามารถใช้ปุ่ม **`CHOOSE…`** เพื่อเลือกไฟล์ `cookies.txt` (Netscape format) จากส่วนสำรองด้านล่าง หรือกด **`REMOVE`** เพื่อลบไฟล์คุกกี้ได้เช่นเดิม
  - **การคุ้มครองข้อมูลส่วนบุคคล:** ระบบไม่มีการแสดงค่าคุกกี้ดิบ และมีตัวกรอง Redaction ป้องกันไม่ให้บันทึกค่าคุกกี้หรือโทเคนลงในไฟล์ Log หรือรายงานข้อผิดพลาดโดยเด็ดขาด (`TC-032`)
* **`yt-dlp.exe` External Binary & Updater:**
  - แสดงเวอร์ชันและตำแหน่งของ `yt-dlp.exe`
  - กดปุ่ม **`UPDATE YT-DLP`** เพื่อเปิดหน้าต่าง **Update `yt-dlp.exe` Binary** (บอร์ด 16) แล้วกด **`UPDATE NOW`** เพื่อดาวน์โหลดเวอร์ชันล่าสุดและตรวจสอบความพร้อมใช้งาน (หากล้มเหลวระบบจะคงไฟล์เดิมไว้โดยอัตโนมัติตาม `TC-031`)
* **การบันทึกการตั้งค่า:**
  - กดปุ่ม **`SAVE SETTINGS`** เพื่อบันทึกลง `config.json` หรือกด **`DISCARD`** เพื่อยกเลิกการแก้ไข

## 8. การดูประวัติและไฟล์ Log (History & Diagnostic Logs)

* **หน้า History (บอร์ด 07):**
  - คลิกแท็บ **`History`** ด้านซ้ายเพื่อดูรายการเพลงที่เคยประมวลผลในอดีต พร้อมตัวกรอง (`ALL`, `COMPLETED`, `FAILED`) และช่องค้นหา
  - กดปุ่ม **`CLEAR HISTORY`** เพื่อล้างประวัติทั้งหมดใน `history.json`
* **หน้า Diagnostic Log Viewer (บอร์ด 17):**
  - คลิกแท็บ **`Logs`** ด้านซ้าย (หรือปุ่ม **`OPEN LOGS`** จากแบนเนอร์แจ้งเตือน) เพื่อเปิดหน้าต่างดูบันทึกการทำงานล่าสุด
  - สามารถกรองตามระดับ (`ALL`, `INFO`, `WARN`, `ERROR`), กด **`↻ REFRESH`** เพื่อโหลดข้อมูลล่าสุด หรือกด **`OPEN LOG FOLDER`** เพื่อเปิดโฟลเดอร์ `logs/` ใน Windows Explorer

## 9. ตารางรหัสข้อผิดพลาดและการแก้ไขเบื้องต้น (Troubleshooting)

รหัสข้อผิดพลาดทั้งหมดตรงตามที่ระบบแจ้งใน UI และไฟล์ Log (`src/pladaz/domain/errors.py`):

| รหัสข้อผิดพลาด | ความหมาย | วิธีแก้ไข |
|---|---|---|
| **`ERR_SDCARD_DISCONNECTED`** | ไม่พบโฟลเดอร์ปลายทาง, การ์ดถูกถอด หรือติดสิทธิ์เขียนไม่ได้ (Read-Only) | ตรวจสอบการเสียบการ์ดรีดเดอร์, ตรวจสอบสลัก Lock บนการ์ด Adapter หรือเลือกโฟลเดอร์ปลายทางใหม่ แล้วกด `▶ RESUME QUEUE` |
| **`ERR_SDCARD_INSUFFICIENT_SPACE`** | พื้นที่ว่างบนการ์ดไม่เพียงพอสำหรับบันทึกไฟล์เพลง | ลบไฟล์ที่ไม่จำเป็นออกจากการ์ด หรือเปลี่ยนการ์ดที่มีพื้นที่ว่างเพียงพอ แล้วกด Retry / Resume |
| **`ERR_SDCARD_VERIFY_FAILED`** | คัดลอกไฟล์ลงการ์ดไม่สำเร็จ หรือขนาดไฟล์ปลายทางไม่ตรงกับต้นฉบับ | ตรวจสอบสภาพการ์ดรีดเดอร์และระบบไฟล์ของการ์ด จากนั้นกดปุ่ม Retry เพื่อลองคัดลอกใหม่ |
| **`ERR_PATH_TOO_LONG`** | เส้นทางไฟล์ปลายทางยาวเกินเพดาน 259 อักขระของ Windows (`DEC-043`) | เลือกโฟลเดอร์ปลายทางที่อยู่ใกล้รากของไดรฟ์มากขึ้น (เช่น `E:\` หรือ `E:\Music` แทนโฟลเดอร์ย่อยหลายชั้น) |
| **`ERR_SOURCE_INVALID_URL`** | ลิงก์ที่ป้อนไม่ใช่ลิงก์ YouTube หรือ YouTube Music ที่ถูกต้อง | ตรวจสอบว่าลิงก์เป็น `https://www.youtube.com/...`, `https://youtu.be/...` หรือ `https://music.youtube.com/...` |
| **`ERR_SOURCE_AUTH_REQUIRED`** | แทร็กนี้จำกัดอายุ (Age-restricted) หรือเป็นเนื้อหาสมาชิก ต้องยืนยันตัวตน (`DEC-052`) | เปิดหน้า Settings → ส่วนที่ 3 (Browser Authentication) เพื่อเปิดใช้งานคุกกี้จากเบราว์เซอร์ที่คุณลงชื่อเข้าใช้ YouTube ไว้ หรือเลือกไฟล์ `cookies.txt` แล้วกด Retry |
| **`ERR_BROWSER_COOKIES_FAILED`** | ไม่สามารถอ่านคุกกี้จากเบราว์เซอร์ที่เลือกได้ (`DEC-052`) | หากเบราว์เซอร์กำลังเปิดอยู่ ให้ปิดหน้าต่างทั้งหมดแล้วลองใหม่ หากเบราว์เซอร์บล็อกการถอดรหัส ให้เลือกเบราว์เซอร์อื่น เช่น Firefox หรือใช้ไฟล์ `cookies.txt` สำรอง |
| **`ERR_SOURCE_EXTRACTION_FAILED`** | ดึงข้อมูลเพลงหรือดาวน์โหลดสตรีมจาก YouTube ไม่สำเร็จ | ตรวจสอบว่าวิดีโอเปิดดูได้ตามปกติ, ลองอัปเดต `yt-dlp.exe` ในหน้า Settings หรือเปิด Browser Authentication |
| **`ERR_SOURCE_NETWORK_TIMEOUT`** | การเชื่อมต่อเครือข่ายหมดเวลาขณะดึงข้อมูลหรือดาวน์โหลด | ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต แล้วกดปุ่ม Retry ที่รายการเพลงนั้น |
| **`ERR_AUDIO_FFMPEG_FAILED`** | การ Remux หรือแปลงเสียงเป็น AAC-LC ด้วย `ffmpeg.exe` ล้มเหลว | ตรวจสอบว่ามีไฟล์ `ffmpeg.exe` อยู่ใน `_internal\bin\` และกด Retry เพื่อลองประมวลผลใหม่ |
| **`ERR_METADATA_TAGGING_FAILED`** | การแปลงภาพปก 800×800 JPEG หรือการเขียนแท็ก MP4 Atoms ล้มเหลว | กดปุ่ม Retry เพื่อลองใหม่ หรือตรวจสอบรายละเอียดเพิ่มเติมในหน้า Diagnostic Logs (บอร์ด 17) |
| **`ERR_VALIDATOR_CORRUPT_FILE`** | ไฟล์ `.m4a` ที่สร้างเสร็จมีขนาดเป็นศูนย์หรือเปิดอ่านโครงสร้าง MP4 ไม่ได้ | กดปุ่ม Retry เพื่อดาวน์โหลดและประมวลผลใหม่อีกครั้ง |
| **`ERR_VALIDATOR_INVALID_CODEC`** | โค้ดเดกเสียงในไฟล์ `.m4a` ไม่ใช่ AAC-LC (`mp4a.40.2`) หรือความยาวเป็น 0 | ตรวจสอบ `ffmpeg.exe` และกดปุ่ม Retry เพื่อประมวลผลเสียงใหม่ |
| **`ERR_VALIDATOR_MISSING_TITLE`** | ไฟล์ `.m4a` ไม่มีแท็กชื่อเพลง (`©nam` / `Title`) ตามกฎ `DEC-030` | ตรวจสอบลิงก์ต้นทาง แล้วกด Retry |
| **`ERR_VALIDATOR_MISSING_COVER`** | เปิดสวิตซ์บังคับต้องมีปก (`Require album art`) แต่ไม่พบภาพปก | ปิดสวิตซ์ `Require album art` ในหน้า Settings หากต้องการให้บันทึกเพลงที่ไม่มีปกได้ |
| **`ERR_TASK_CANCELLED`** | งานถูกกดยกเลิกโดยผู้ใช้ระหว่างกำลังทำงาน (`DEC-042`) | หากต้องการดาวน์โหลดเพลงนี้อีกครั้ง ให้กดปุ่ม `↻` (Retry) ที่แถวรายการ แล้วกด `▶ RESUME QUEUE` |
| **`ERR_CONFIG_CORRUPT`** | ไฟล์ `config.json` หรือ `history.json` เสียหาย | ระบบสำรองไฟล์เดิมเป็น `.corrupt-<timestamp>` และสร้างไฟล์ค่าเริ่มต้นใหม่ให้อัตโนมัติ สามารถตั้งค่าปลายทางใหม่ได้ทันที |
| **`ERR_YTDLP_UPDATE_FAILED`** | การดาวน์โหลดหรือตรวจสอบไฟล์ `yt-dlp.exe` เวอร์ชันใหม่ล้มเหลว | ระบบคงไฟล์ `yt-dlp.exe` เดิมไว้ให้อัตโนมัติ ตรวจสอบอินเทอร์เน็ตแล้วลองกดอัปเดตใหม่ หรือดาวน์โหลดมาวางด้วยตนเอง |
